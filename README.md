# Beginner web messaging app

Hello, this here is a web messaging app utilizing the socket.io library. I created it during a Web Programming III lab at Heritage College. The  styling was provided to me alongside with the basic layout of the page. The server and client side logic was written by myself using the guided instructions and documentation that I could access.

The page is live at this URL: [Web messaging app](https://web-labs-g2sg.onrender.com/)

Enjoy messaging with somebody else and trying it out.

Currently, the messages are not saved and will not stay after the page is reloaded. But, it is something that I would maybe implement in the future.
